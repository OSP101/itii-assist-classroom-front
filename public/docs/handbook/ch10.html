การเช็คชื่อเข้าเรียน

10.1 ภาพรวม#

โมดูลการเช็คชื่อช่วยให้อาจารย์เปิด "รอบการเช็คชื่อ" ประจำคาบ และให้นักศึกษายืนยันการเข้าเรียนผ่านมือถือได้ทันที โดยไม่ต้องขานชื่อทีละคน ท่านสามารถแสดง PIN 6 หลัก และ QR Code ให้นักศึกษาสแกนหรือกรอก กำหนดเกณฑ์ "สาย" อัตโนมัติ เลือกให้ตรวจ ตำแหน่ง GPS ติดตามผลแบบเรียลไทม์ และดูสรุป มา / สาย / ลา / ขาด พร้อมแก้ไขสถานะย้อนหลังได้

10.2 เข้าสู่หน้าจัดการเช็คชื่อ#

  1. ที่แถบเมนูด้านซ้าย คลิก จัดการการเช็คชื่อ เพื่อขยายเมนูย่อย
  2. คลิกเมนูย่อย เช็คชื่อ

ระบบจะแสดงหน้า การเช็คชื่อเข้าเรียน ซึ่งรวมรอบเช็คชื่อทั้งหมดของวิชา

  1. ปุ่ม สร้างรอบเช็คชื่อ สำหรับสร้างรอบใหม่
  2. แถบสรุปจำนวนรอบ ทั้งหมด / กำลังเปิด / ฉบับร่าง / ปิดแล้ว
  3. ปุ่มจัดการรายรอบ ได้แก่ ดู สถิติ และเมนูเพิ่มเติมสำหรับแก้ไขหรือลบ (ปุ่ม "เปิดหน้าจอเช็คชื่อ" ที่มุมขวาบนใช้ฉาย PIN/QR ขึ้นจอหน้าห้อง)

10.3 สร้างรอบการเช็คชื่อ#

คลิกปุ่ม สร้างรอบเช็คชื่อ ระบบจะเปิดหน้าต่างให้กรอกรายละเอียด

  1. กรอก ชื่อรอบการเช็คชื่อ เช่น "เช็คชื่อสัปดาห์ที่ 1"
  2. เลือก กลุ่มเรียน (Section) ที่จะเช็คชื่อ (เลือกได้มากกว่าหนึ่งหมู่)
  3. เลือก ประเภทการเรียน เป็นบรรยายหรือปฏิบัติ
  4. กำหนด เวลาเริ่มต้น และ เวลาสิ้นสุด ของช่วงรับการเช็คชื่อ
  5. กำหนด เวลาตัดสาย นักศึกษาที่เช็คชื่อหลังเวลานี้จะถูกนับเป็น "สาย" โดยอัตโนมัติ
  6. เปิด เปลี่ยน PIN อัตโนมัติ เพื่อให้ระบบสุ่ม PIN ใหม่ทุก 1 นาที (แนะนำให้เปิดไว้)
  7. เปิด ตรวจสอบตำแหน่ง GPS หากต้องการให้นักศึกษาอยู่ในรัศมีห้องเรียนจึงจะเช็คชื่อได้
  8. เมื่อตั้งค่าครบ คลิกปุ่ม สร้างรอบเช็คชื่อ
ข้อควรทราบ

เมื่อเปิด "เปลี่ยน PIN อัตโนมัติ" ตัวเลข PIN บนจอจะเปลี่ยนทุก 1 นาที เพื่อป้องกันการส่งต่อ PIN ให้เพื่อนที่ไม่ได้เข้าเรียน จึงควรฉาย PIN/QR ให้นักศึกษาเห็นตลอดช่วงเช็คชื่อ

10.4 เปิดรอบและแสดง PIN / QR#

เมื่อสร้างรอบสำเร็จ ระบบจะแจ้งเตือน และรอบใหม่จะปรากฏบนสุดของรายการ

  1. สังเกตสถานะเปลี่ยนเป็น กำลังเปิด ซึ่งหมายความว่ารอบพร้อมรับการเช็คชื่อแล้ว
  2. คลิกไอคอน ดู ที่ท้ายแถวของรอบนั้น เพื่อเปิดหน้าจอเช็คชื่อสด

หน้าจอเช็คชื่อสดจะเปิดขึ้นพร้อมองค์ประกอบสำคัญ

  1. PIN CODE รหัส 6 หลักให้นักศึกษากรอก
  2. QR CODE ให้นักศึกษาสแกนเพื่อเข้าหน้าเช็คชื่อ (คลิกที่ภาพเพื่อขยาย)
  3. เกณฑ์เวลาสาย ย้ำเวลาที่จะเริ่มนับว่าสาย
  4. สถิติภาพรวม จำนวนเช็คชื่อแล้ว / มาเรียน / สาย / ลา / ขาด แบบเรียลไทม์
  5. รายชื่อผู้เช็คชื่อ ที่อัปเดตทันทีเมื่อนักศึกษาเช็คชื่อสำเร็จ
  6. ปุ่ม ปิดรับการเช็คชื่อ สำหรับปิดรอบเมื่อหมดเวลา
ข้อควรทราบ

นักศึกษาเข้าสู่ระบบในแอปฝั่งนักศึกษา (บัญชี KKU Mail) แล้วเช็คชื่อผ่านการสแกน QR หรือกรอก PIN ที่แสดงบนจอ ระบบยืนยันด้วย PIN ที่หมุนเวียนและการตรวจ GPS (ถ้าเปิดใช้งาน) จึงสะดวกและรวดเร็วสำหรับการใช้งานผ่านมือถือหน้าห้อง

10.5 ปิดรอบและดูสรุป มา / สาย / ลา / ขาด#

เมื่อหมดเวลา ให้กดปุ่ม ปิดรับการเช็คชื่อ ระบบจะปิดรอบและคืน PIN เข้าระบบทันที จากนั้นเปิดดูสรุปได้โดยคลิกไอคอน สถิติ ที่ท้ายแถวของรอบนั้น

  1. สรุปจำนวน ทั้งหมด / มา / สาย / ลา / ขาด ของรอบนี้
  2. อัตราการเข้าเรียน คิดเป็นเปอร์เซ็นต์
  3. คอลัมน์สถานะ แสดงสถานะรายบุคคลพร้อมเวลาที่เช็คชื่อ
  4. ปุ่มแก้ไข สำหรับปรับสถานะรายคน

10.6 แก้ไขสถานะการเข้าเรียนย้อนหลัง#

กรณีนักศึกษาลาป่วย มาสายเพราะเหตุสุดวิสัย หรือระบบบันทึกคลาดเคลื่อน อาจารย์สามารถปรับสถานะย้อนหลังได้

  1. ที่หน้าสรุปการเช็คชื่อ คลิกปุ่มแก้ไขท้ายแถวของนักศึกษาที่ต้องการ
  2. เลือกสถานะใหม่ มา / สาย / ลา / ขาด
  3. ใส่หมายเหตุเหตุผลการแก้ไข เพื่อให้ตรวจสอบย้อนหลังได้
  4. บันทึก ระบบจะปรับตัวเลขสรุปและอัตราการเข้าเรียนให้อัตโนมัติ
