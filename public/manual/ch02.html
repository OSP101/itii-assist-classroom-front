อาจารย์ผู้สอน บทที่ 4บทนำและการเข้าสู่ระบบ บทที่ 5การจัดการหมู่เรียนและกลุ่ม บทที่ 6การจัดการสมาชิกและสิทธิ์ผู้ช่วยสอน บทที่ 7งานมอบหมายและการให้คะแนน บทที่ 8การอนุมัติคำขอแก้ไขคะแนน บทที่ 9การสอบและคะแนนสอบ บทที่ 10การเช็คชื่อเข้าเรียน บทที่ 11ระบบคิวตรวจงาน บทที่ 12การจับคู่จอแสดงผลหน้าห้อง บทที่ 13การติดตามผลงานทีมและบันทึกกิจกรรม บทที่ 14การตั้งค่ารายวิชา
ผู้ช่วยสอน บทที่ 15บทนำและบทบาทผู้ช่วยสอน บทที่ 16ระบบคิวและหน้ารับงาน (Worker) บทที่ 17การให้คะแนนและการขอแก้ไขคะแนน บทที่ 18งานอื่น ๆ ตามสิทธิ์ที่ได้รับ

บทที่ 2

บัญชีผู้ใช้และความปลอดภัย (ทุกบทบาท)

เนื้อหาบทนี้ใช้ได้กับผู้ดูแลระบบ อาจารย์ และผู้ช่วยสอนทุกคน เนื่องจากหน้าตั้งค่าบัญชีเป็นหน้าเดียวกันทุกบทบาท

2.1 การเข้าสู่ระบบ#

  1. เปิดเว็บเบราว์เซอร์ไปที่ที่อยู่เว็บของระบบ ระบบจะแสดงหน้าเข้าสู่ระบบ
  2. กรอก ชื่อผู้ใช้ ในช่องแรก
  3. กรอก รหัสผ่าน ในช่องถัดมา
  4. คลิกปุ่ม เข้าสู่ระบบ หรือเลือกเข้าสู่ระบบผ่านบัญชี Google / GitHub ที่ผูกไว้ (นักศึกษาใช้ปุ่ม "ล็อกอินนักศึกษา" ที่มุมขวาบน)
ข้อควรทราบ

ผู้ใช้ที่ผู้ดูแลระบบสร้างให้ใหม่จะได้รับรหัสผ่านชั่วคราว เมื่อเข้าสู่ระบบครั้งแรกระบบจะบังคับให้เปลี่ยนรหัสผ่านก่อนใช้งาน และหากลืมรหัสผ่านสามารถกด "ลืมรหัสผ่าน?" เพื่อรับลิงก์รีเซ็ตทางอีเมลได้

2.2 ข้อมูลส่วนตัวและรูปโปรไฟล์#

เข้าหน้าตั้งค่าบัญชีโดยคลิกรูปโปรไฟล์ที่มุมขวาบน แล้วเลือก ตั้งค่าโปรไฟล์

  1. เมนูด้านซ้ายแบ่งเป็น 4 ส่วน ได้แก่ ข้อมูลส่วนตัว การยืนยันตัวตน อุปกรณ์ที่เข้าสู่ระบบ และการแสดงผลและภาษา
  2. ปุ่ม อัปโหลดรูปใหม่ ใช้เปลี่ยนรูปโปรไฟล์ (JPG/PNG/GIF ไม่เกิน 5MB)
  3. แก้ไข ชื่อ-นามสกุลและอีเมล แล้วกดบันทึกการเปลี่ยนแปลง (ชื่อผู้ใช้ Username แก้ไขไม่ได้)

2.3 รหัสผ่าน การยืนยันตัวตนสองชั้น และการเชื่อมบัญชี#

ที่เมนู การยืนยันตัวตน

  1. ปุ่ม เปลี่ยนรหัสผ่าน ใช้เปลี่ยนรหัสผ่านของบัญชี
  2. ปุ่ม ตั้งค่า 2FA ใช้เปิดการยืนยันตัวตนสองขั้นตอน รองรับทั้งแอป Authenticator (TOTP) และรหัสทางอีเมล พร้อมรหัสสำรอง (backup codes) สำหรับกรณีฉุกเฉิน เมื่อเปิดใช้แล้ว การเข้าสู่ระบบทุกครั้งต้องยืนยันรหัสเพิ่ม
  3. ส่วน เชื่อมต่อบัญชี ใช้เชื่อมหรือยกเลิกการเชื่อมบัญชี Google และ GitHub เพื่อเข้าสู่ระบบได้โดยไม่ต้องกรอกรหัสผ่าน
ข้อควรทราบ

สำหรับผู้ดูแลระบบ การเปิด 2FA มีความจำเป็นเป็นพิเศษ เพราะการดำเนินงานสำคัญของระบบ (สำรอง/กู้คืนข้อมูล รีสตาร์ท โหมดบำรุงรักษา ฯลฯ) ต้องยืนยันรหัส 2FA ซ้ำทุกครั้ง หากยังไม่เปิด 2FA จะไม่สามารถทำรายการเหล่านั้นได้

2.4 อุปกรณ์และเซสชันที่เข้าสู่ระบบ#

ที่เมนู อุปกรณ์ที่เข้าสู่ระบบ ระบบแสดงทุกอุปกรณ์และเบราว์เซอร์ที่บัญชีนี้เข้าสู่ระบบค้างไว้

  1. แต่ละรายการแสดง ระบบปฏิบัติการ เบราว์เซอร์ IP และเวลาเข้าสู่ระบบ โดยเซสชันที่ใช้อยู่ปัจจุบันมีป้ายกำกับ "เซสชันปัจจุบัน"
  2. ปุ่ม ออกจากระบบทั้งหมด ใช้บังคับออกจากระบบทุกอุปกรณ์พร้อมกัน
  3. ไอคอนท้ายแต่ละรายการใช้ เพิกถอนเซสชันรายอุปกรณ์ เมื่อพบอุปกรณ์ที่ไม่รู้จักหรือเลิกใช้แล้ว

2.5 การแสดงผลและภาษา#

ที่เมนู การแสดงผลและภาษา ปรับ ธีม (ตามระบบ/สว่าง/มืด) ภาษา (ไทย/อังกฤษ) และ ขนาดฟอนต์ (เล็ก/กลาง/ใหญ่) ได้ตามความถนัด ระบบบันทึกการตั้งค่าเข้ากับบัญชีโดยอัตโนมัติ

2.6 การแจ้งเตือน#

คลิกไอคอน กระดิ่ง ที่มุมขวาบนของทุกหน้า เพื่อเปิดกล่องการแจ้งเตือน

  1. ปุ่ม อ่านทั้งหมด ทำเครื่องหมายอ่านทุกรายการ และ ลบที่อ่านแล้ว ใช้เคลียร์รายการ
  2. แท็บ ทั้งหมด / ยังไม่ได้อ่าน ใช้กรองรายการ
  3. ประเภทการแจ้งเตือนครอบคลุม งาน การเช็คชื่อ คิว การแก้คะแนน และประกาศจากผู้ดูแลระบบ นอกจากนี้ระบบยังรองรับ Push Notification ที่แจ้งเตือนถึงอุปกรณ์แม้ไม่ได้เปิดหน้าเว็บอยู่ (ใช้ปลุกผู้ช่วยสอนเมื่อมีคิวใหม่ โดยระบบจะขออนุญาตเมื่อเริ่มรับงาน)

2.7 ศูนย์ช่วยเหลือ#

หน้า ศูนย์ช่วยเหลือ (ลิงก์ท้ายทุกหน้า) รวมคู่มือการใช้งาน คำถามที่พบบ่อย การตรวจสอบสถานะระบบ ช่องทางติดต่อทีมสนับสนุน และการแจ้งปัญหาความปลอดภัยไว้ในที่เดียว ผู้ใช้ทุกบทบาทรวมถึงบุคคลทั่วไปสามารถส่งคำขอสนับสนุนได้
