# Quick Start 1 หน้า: ผู้ช่วยสอน (TA)

## เป้าหมาย
เริ่มงาน TA ได้ทันที โดยไม่เกินสิทธิ์ที่ได้รับ

## 10 ขั้นตอนหลัก
1. เข้า `/(instructor)/home` แล้วเลือกรายวิชา
2. ตรวจ permission ของตนให้ชัดก่อนเริ่มงาน
3. ตรวจรายการงานที่ต้องดูแลในสัปดาห์นี้
4. ถ้ามีสิทธิ์ attendance ให้เตรียมรอบเช็กชื่อ
5. ถ้ามีสิทธิ์ score ให้เริ่มตรวจงานตาม rubric
6. บันทึกคะแนนเป็น batch เล็กและตรวจซ้ำ
7. หากพบคะแนนผิด ให้ส่ง score edit request
8. เข้าหน้า queue worker เมื่อมี session คิว
9. อัปเดตสถานะคิวให้ตรงหน้างานเสมอ
10. สรุปงานส่งผู้สอนทุกสัปดาห์

## เช็กลิสต์ประจำวัน
- สิทธิ์พร้อมใช้งาน
- งานค้างถูกจัดลำดับแล้ว
- รายการที่ต้องขออนุมัติถูกส่งครบ
- คิวและเช็กชื่อปิดสถานะถูกต้อง

## รูปแบบสรุปส่งผู้สอน
- งานตรวจ: เสร็จ X/Y
- เช็กชื่อ: ปัญหา N เคส
- คิว: ทั้งหมด A, เสร็จ B, ยกเลิก C
- คำขอแก้คะแนน: ค้าง D รายการ

## ถ้าเมนูไม่ขึ้นหรือกดไม่ได้
1. ตรวจบัญชีที่ล็อกอิน
2. ออกจากระบบและเข้าใหม่
3. ส่งชื่อรายวิชา + เมนูที่ติด + รูปหน้าจอให้ผู้สอน
