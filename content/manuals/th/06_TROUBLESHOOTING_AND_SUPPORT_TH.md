# Troubleshooting และแนวทางซัพพอร์ต

## 1) ปัญหาเกี่ยวกับการเข้าสู่ระบบ

### อาการ
- ล็อกอินไม่ผ่าน
- ไม่ได้รับอีเมล reset password
- ยืนยัน 2FA ไม่สำเร็จ

### วิธีแก้ทีละขั้น
1. ตรวจชื่อบัญชี/อีเมลว่าถูกต้อง
2. ตรวจว่าใช้รหัสผ่านล่าสุด
3. ใช้เมนูลืมรหัสผ่าน
4. ตรวจโฟลเดอร์ spam ของอีเมล
5. ตรวจเวลาบนอุปกรณ์ให้ตรง (สำคัญกับ TOTP)
6. ถ้ายังไม่ได้ ให้ติดต่อผู้ดูแลระบบ

ข้อมูลที่ควรส่งให้ซัพพอร์ต:
- อีเมลที่ใช้ล็อกอิน
- เวลาเกิดปัญหา
- ข้อความ error
- ภาพหน้าจอ

---

## 2) ปัญหาเรื่องสิทธิ์

### อาการ
- เห็นเมนูไม่ครบ
- กดปุ่มแล้วขึ้น forbidden/unauthorized

### วิธีแก้
1. ตรวจว่าล็อกอินด้วยบัญชีที่ถูกต้อง
2. ตรวจบทบาทในระบบ
3. ตรวจว่าถูกเพิ่มเป็นสมาชิกในรายวิชานั้นแล้ว
4. สำหรับ TA ให้ผู้สอนตรวจ Course Permission
5. ออกจากระบบและเข้าใหม่

---

## 3) ปัญหาเช็กชื่อ

### อาการ
- เปิดหน้าเช็กชื่อได้แต่ส่งไม่สำเร็จ
- ขึ้นพิกัดไม่ผ่าน
- บอกว่า session ปิดแล้ว

### วิธีแก้
1. ตรวจว่า session ยัง active
2. ตรวจสิทธิ์ location ใน browser
3. ปิด VPN/Proxy ชั่วคราวถ้ามีผลกับ location
4. ตรวจว่าอยู่ในพื้นที่ที่นโยบายรายวิชากำหนด
5. ลอง browser อื่น

หลักฐานที่ต้องเก็บ:
- ชื่อรายวิชา/section
- session id หรือชื่อ session
- เวลาและภาพหน้าจอ

---

## 4) ปัญหาระบบคิว

### อาการ
- จองคิวไม่ได้
- สถานะคิวไม่อัปเดต
- worker ไม่เห็นคิว

### วิธีแก้
1. ตรวจว่า session คิวยังเปิด
2. ตรวจ PIN ถ้ารายวิชากำหนด
3. รีเฟรชหน้าและเข้าใหม่
4. ตรวจเครือข่ายอินเทอร์เน็ต
5. ให้ TA/ผู้สอนตรวจสถานะฝั่ง worker

---

## 5) ปัญหาคะแนน

### อาการ
- คะแนนไม่ขึ้น
- คะแนนไม่ตรง
- summary กับรายละเอียดไม่เท่ากัน

### วิธีแก้
1. ตรวจว่าผู้สอนเปิดเผยคะแนนแล้ว
2. ตรวจว่าบันทึกคะแนนสำเร็จจริง
3. ตรวจคำขอแก้คะแนนค้างอนุมัติหรือไม่
4. ตรวจว่าเป็นคะแนนงาน/สอบ/โบนัสหมวดเดียวกัน
5. ให้ผู้สอนตรวจ score matrix และ activity log

---

## 6) SLA การตอบกลับแนะนำ (สำหรับทีมดูแลวิชา)

1. ปัญหาเข้าเรียนไม่ได้/เช็กชื่อไม่ได้ระหว่างคาบ
- ตอบกลับภายใน 5-15 นาที

2. ปัญหาคะแนน/สิทธิ์รายวิชา
- ตอบกลับภายใน 1 วันทำการ

3. ปัญหาบัญชี/2FA
- ตอบกลับภายใน 1 วันทำการ

หัวข้อ: [รายวิชา] [ประเภทปัญหา] [รหัสนักศึกษา/บัญชี]
