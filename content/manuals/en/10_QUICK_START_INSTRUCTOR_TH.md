# One-page quick start for instructors

Use this checklist when you need the minimum set of setup steps to launch a course safely before the first teaching day.

## Goal
Make the course ready for real usage on the first day.

## 10 main steps
1. Open `/(instructor)/home` and select the course.
2. Verify the course details such as code, term, and year.
3. Create and review sections in the `sections` tab.
4. Add TAs and co-instructors in the `people` tab.
5. Assign TA permissions based on real responsibilities.
6. Add students to every section.
7. Create the first assignment in the `assignments` tab.
8. Configure the first attendance session in the `attendance` tab.
9. Prepare a help or review queue in the `queue` tab.
10. Review the `scores` and `settings` pages before teaching starts.

## Checklist before class starts
- Student rosters are in the correct sections
- TAs can see the menus they need
- The first assignment is already published
- The attendance session is ready to open
- A fallback plan exists if the system has problems, such as collecting evidence for later correction

## Checklist during the term
- Grade within each assignment cycle
- Clear pending score edit requests
- Review TA permissions at mid-term
- Review queue and attendance statistics to improve teaching operations

## Close the term safely
1. Verify scores are complete for every assignment.
2. Verify exam scores and bonus points.
3. Clear remaining score edit requests.
4. Review the course activity log.
5. Close the course according to policy.
