# Teaching assistant step-by-step guide

Use this guide to verify your permissions, handle weekly TA work correctly, and report the right status back to the instructor.

## Important before you start
- What a TA can do depends on course permissions
- If a menu is missing or disabled, ask the instructor to adjust your access

## A. Check your permissions and assigned courses

1. Sign in and go to `/(instructor)/home`.
2. Select the course assigned to you.
3. Open the `people` tab or the permissions view to confirm your access.
4. Check the work items you are responsible for this week.

Expected outcome:
- You clearly understand the scope of your work

---

## B. Attendance tasks often handled by TAs

### If you can create or edit sessions
1. Open the `attendance` tab.
2. Create a session for the section you support.
3. Set the time and conditions such as PIN or GPS.
4. Inform students when the session opens.
5. Close the session when the time window ends.

### If you can only update attendance status
1. Open the existing session.
2. Review the attendance records.
3. Update status per student or in bulk based on evidence.
4. Add a reason every time you change a record.

---

## C. Review work and grade

1. Open the `assignments` tab to review assignment rules.
2. Go to the `scores` tab and choose the work that needs grading.
3. Grade using the rubric defined by the instructor.
4. If it is group work, use the group grading mode.
5. If the volume is high, use bulk grading carefully.
6. Review totals in `score summary`.

Ways to reduce errors:
- Check student name and student ID before saving each score
- Work in small batches so rechecking is easier

---

## D. Submit a score edit request

### When to use it
- You entered a score incorrectly
- A new piece of evidence requires a score change
- A group score needs to be updated based on a rule agreed with the instructor

### Steps
1. Open the score entry that needs to change.
2. Create a score edit request.
3. Fill in all required details:
- Previous score
- Requested score
- Reason
- Attached evidence if available
4. Submit the request.
5. Track the approval status on the request page.

Important note:
- Avoid direct score changes when the course uses an approval workflow.

---

## E. Queue worker tasks

1. Open the course `queue` tab.
2. Enter the worker page for the active session.
3. Serve students in order.
4. Update the queue status immediately when work starts and ends.
5. If a student is not ready, skip them according to course policy.
6. Before class ends, report any remaining queue backlog to the instructor.

Checklist during queue operation:
- The system status should match the real situation in class
- Do not leave an item in the same status longer than necessary

---

## F. Team and section student tasks

### If you can manage teams
1. Open the `sections` or `teams` tab.
2. Create teams or rename them.
3. Add or remove members.
4. Verify that every team is complete.

### If you can manage students
1. Open the section roster.
2. Add or remove students.
3. If a removal was incorrect, use restore when the system allows it.

---

## G. Weekly summary for the instructor

1. Summarize how many assignments were reviewed and how many remain.
2. Summarize the score cases that required edit requests.
3. Summarize attendance and queue issues.
4. Send a short report listing the items that still need an instructor decision.

Suggested template:
- Assignment: completed X/Y
- Attendance: N unusual cases
- Queue: total A, completed B, canceled C
- Requests: D items waiting for approval
