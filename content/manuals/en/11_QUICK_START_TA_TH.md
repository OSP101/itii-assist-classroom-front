# One-page quick start for teaching assistants

Use this checklist when you need to start TA work immediately without going beyond the permissions assigned to you.

## Goal
Start TA work right away without exceeding your assigned permissions.

## 10 main steps
1. Open `/(instructor)/home` and select the course.
2. Confirm your permissions before starting any work.
3. Check the work items you own this week.
4. If you have attendance access, prepare the attendance session.
5. If you have grading access, start reviewing work with the rubric.
6. Save scores in small batches and review them again.
7. If a score is wrong, submit a score edit request.
8. Open the queue worker page when a queue session is active.
9. Keep queue status aligned with the real in-class workflow.
10. Send a weekly summary to the instructor.

## Daily checklist
- Permissions are sufficient for today's work
- Pending work is already prioritized
- Approval-required items were submitted
- Queue and attendance statuses were closed correctly

## Weekly report format
- Reviewed work: completed X/Y
- Attendance: N issue cases
- Queue: total A, completed B, canceled C
- Score edit requests: D pending items

## If a menu is missing or disabled
1. Verify the account you signed in with.
2. Sign out and sign in again.
3. Send the course name, blocked menu, and screenshot to the instructor.
